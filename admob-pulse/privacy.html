Privacy Policy

This policy applies specifically to AdMob Pulse, the personal Android reporting tool maintained by The Tree Team. It describes the application as implemented in version 1.0. The general advertising policy for other Tree Team applications does not describe this application's reporting features.

Data accessed from Google

After the account holder authorizes read-only AdMob access, the application accesses the publisher account name or ID, reporting currency, reporting time zone and requested Network or Mediation report data. Report data can include dates, application and ad-unit identifiers and labels, countries, ad formats, platforms, ad sources, estimated earnings, impressions, clicks, ad requests and matched requests. Country data is aggregated report data, not the device's GPS location.

The requested scope is https://www.googleapis.com/auth/admob.readonly. Although that scope permits read-only access to additional AdMob data, this application uses account metadata and performance reports for its implemented features. It does not request permission to modify AdMob settings.

Purpose and use

Data is used only to display and filter reports, calculate performance ratios and comparisons, draw charts, provide an offline cache and create CSV exports requested by the account holder. Data is not used for advertising, marketing, profiling for unrelated purposes, credit decisions or training general-purpose AI or machine-learning models.

Authorization and tokens

Google Identity Services handles account selection and authorization. The application does not ask for or store the Google account password. A short-lived access token is kept only in the application session's memory and is sent to Google's AdMob API over HTTPS. The application does not request or store a refresh token. Google services handle their own account and authorization records according to Google's policies.

Device storage and retention

Publisher metadata is stored in private application preferences. Downloaded report responses are cached in the application's private files, with a total cache limit of 24 MiB. Cached data is reused for 15 minutes when possible, and older cached data can be displayed when no current data is available. That 15-minute reuse period is not a deletion deadline: a report can remain stored until it is evicted, manually cleared or the application's local data is removed.

AdMob Pulse excludes its private application files and preferences from Android cloud backup and device transfer using its app configuration. Android and the device provide the storage protections for those private files.

Sharing and third parties

The application communicates directly with Google to authorize access and retrieve reports. There is no developer-operated server that automatically receives report data, and the application does not include an advertising SDK or an analytics SDK. Google API data is not sold or automatically shared with the developer or other third parties.

If the account holder exports a CSV file, Android's document picker lets them choose a destination. Choosing a cloud storage provider can send that exported file to the chosen provider. Files exported or shared by the account holder are controlled by that destination and are outside the application's private cache. A temporary export copy can exist in the application's cache until export finishes or is cancelled; an interrupted export can leave a temporary copy until it is cleared.

This documentation website is hosted on GitHub Pages. Website hosting and Google services operate under their respective privacy policies: GitHub Privacy Statement and Google Privacy Policy.

Deleting data and revoking access

  • Use Xóa cache báo cáo in the application to delete locally cached reports.
  • Use Ngắt kết nối & xóa dữ liệu to clear local account metadata, reports and the temporary export file.
  • Use Android's application settings to clear all app data or uninstall the application.
  • To revoke Google's authorization, remove the application's access at Google Account third-party connections. Local disconnection does not itself revoke the Google-side grant.
  • Delete exported CSV files separately from the storage destination you selected. Clearing the application's cache or uninstalling it does not delete those exports.

Google API data use

AdMob Pulse's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements where applicable. The application's disclosed reporting features define its use of that information.

Personal use and changes

This tool is intended for the developer's own authorized publisher account, rather than as a public service. If its data practices change, this policy and the in-application disclosures will be updated, and any additional Google permissions will be requested before the new access is used.

Contact

For questions about this application or its data practices, contact thetreeteam@outlook.com. Messages you choose to send to that address are used to answer your request. Do not include passwords, access tokens or unnecessary report data.
