AdMob Pulse is a lightweight Android application used privately by its developer to review estimated advertising earnings and performance reports for their own AdMob account.

Personal use

This page documents the application and its handling of Google user data. The application is not offered for public download or registration here.

What the application does

  • Shows estimated earnings for today, yesterday, this month and selected date ranges.
  • Draws daily line and bar charts and compares earnings with the preceding period.
  • Breaks down reports by application, country, ad format, ad unit, platform and, for Mediation reports, ad source.
  • Displays impressions, clicks, requests, eCPM, CTR, match rate and show rate.
  • Saves a limited report cache on the device and exports a selected report to CSV when requested.

Why Google access is requested

The Android application uses Google's authorization flow and requests https://www.googleapis.com/auth/admob.readonly. It calls the official AdMob API to read publisher account metadata and Network or Mediation reports. It uses this data only to provide the dashboard, charts, filters, comparisons, offline cache and user-requested exports.

Reports are requested directly from Google. The application has no developer-operated reporting server, advertising SDK or analytics SDK. It does not change AdMob settings or request access to Gmail, contacts or unrelated files.

Estimated earnings

Displayed earnings are estimates supplied by Google and can change. They are not a finalized payment balance or payment history. For payment details, use the official AdMob interface.
